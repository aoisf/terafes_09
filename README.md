# 開発・作業ガイド

## 【重要】開発・ファイル操作ルール
* **作業は必ず自分のブランチで行うこと**
* **【厳禁】Windowsのエクスプローラーから直接ファイルを移動・名前変更・削除しないこと**
  * EclipseのGitプラグイン（EGit）でリポジトリ管理・追跡を行っているため、エクスプローラーから直接触るとファイルの同期ズレや管理情報の破損が発生し、復旧が困難になります。
  * ファイルの追加・移動・名前変更・削除は、**必ずEclipseのパッケージ・エクスプローラー上から**行ってください。
* **【厳禁】外部ライブラリ（.jarファイルなど）の無断追加の禁止**
  * プロジェクトは**追加ファイルなし（JDK標準機能および標準のServlet/JSP APIのみ）で動作する構成を厳守**してください。
  * 個人で勝手にJARを追加すると、ビルドパス（.classpath）の破損や環境差異による動作不良の原因になります。
  * どうしても追加のライブラリやJARを使いたい場合は、**勝手に追加せず、必ず事前にチームメンバーへ相談**してください。

## AIにプロジェクト全体を共有する方法
※ 日本語コメント等は文字化けする場合がありますが、コードの構造把握用として使用できます。

1. コマンドプロンプト（cmd）を開き、プロジェクトのルートディレクトリで以下を実行：
   ```bat
   powershell -c "gci -r -inc *.java,*.jsp,*.js,*.css|%{'`n===== '+$_.FullName+' =====`n';gc $_}>all.txt"
   
2. 生成された `all.txt` をそのままAIにdrop
3. 要件が済んだら必ず削除してそのままコミット・プッシュしないこと
