# 開発・作業ガイド

## 【重要】開発・ファイル操作ルール
* **作業は必ず自分のブランチで行うこと**
* **【厳禁】Windowsのエクスプローラーから直接ファイルを移動・名前変更・削除しないこと**
  * EclipseのGitプラグイン（EGit）でリポジトリ管理・追跡を行っているため、エクスプローラーから直接触るとファイルの同期ズレや管理情報の破損が発生し、復旧が非常に困難になります。
  * ファイルの追加・移動・名前変更・削除は、**必ずEclipseのパッケージ・エクスプローラー上から**行ってください。
